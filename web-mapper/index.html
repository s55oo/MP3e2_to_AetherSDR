Profile for AetherSDR

  1. Paste into a plain text file named Hercules MP3 e2.xml.
  2. In AetherSDR open the MIDI mapping dialog, click Import… and choose that file.
  3. Or drop it straight into the profile folder: ~/.config/AetherSDR/midi/ (Linux), ~/Library/Preferences/AetherSDR/midi/ (macOS) or %LOCALAPPDATA%\AetherSDR\midi\ (Windows), then Load it.
